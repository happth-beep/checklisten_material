2. Bereitstellung der Website über GitHub Pages

Die Seiten und zugehörigen Dateien werden über GitHub Pages ausgeliefert. Bei einem Abruf fallen technische Daten an: IP-Adresse, angeforderte Internetadresse bzw. Datei, Zeitpunkt sowie vom Browser übermittelte Angaben, etwa zum Browser und gegebenenfalls zur zuvor besuchten Seite (Referrer). 3. Cookies, Suche und Lernfunktionen

Der Websitecode setzt keine Cookies, verwendet keinen Browser-Dauerspeicher für Lernstände und bindet keine Analyse-, Werbe- oder Social-Media-Dienste ein. Schriftarten werden aus den auf Ihrem Gerät verfügbaren Systemschriften verwendet; Bilder, Skripte und Formatvorlagen werden zusammen mit der Website bereitgestellt.

Die Suche filtert die bereits geladene Materialübersicht ausschließlich im Browser. Suchbegriffe werden durch diese Funktion nicht übertragen. Das Öffnen von Informationen, Hilfen und Lösungen erfolgt ebenfalls lokal. Die Druckfunktion verwendet den Druckdialog Ihres Browsers. Es gibt keine Benutzerkonten, Eingabefelder zur Abgabe von Lösungen, Bewertungen oder personenbezogenen Lernprofile.

Das Abrufen weiterer Seiten, Grafiken oder Druckvorlagen löst jeweils die unter Abschnitt 2 beschriebenen Verbindungen zum Hostinganbieter aus.
